Guitar GirlFan Memorial Build

这是玩家为《吉他少女》做的离线纪念版。补丁会把服务端一起装进游戏，往后即使没有网络，莉莉也能继续弹给你听。

从原版到纪念版

  1. 准备原版 XAPK

    需要 Android 最终版 Guitar Girl 8.0.0 的完整、未修改 XAPK。先找找自己的下载备份；也可以在 APKPure 等应用目录核对游戏名和版本。请使用你有权使用的副本。

  2. 制作并下载

    在本页选择原包。版本符合要求后，点「制作纪念版」，再点出现的下载按钮，把新的 XAPK 保存到手机。

  3. 安装，回去听歌

    用支持 XAPK 的安装器打开刚下载的纪念版文件，按 Android 提示完成安装。打开 Guitar Girl Fan Memorial Build，点启动，戴上耳机，玩得开心！

按自己的节奏养成

多项升级的要求降到原版的十分之一；原来需要付费的商店礼包也可以免费领取。

补回错过的限定

打开游戏设置里的「纪念版功能」，就能通过邮箱领取绝版服装和吉他、补充资源，也可以切换想玩的星级通行证。

把重逢留给想念她的人

在论坛或社媒遇到怀念《吉他少女》的人，欢迎回帖告诉他们可以回来玩了。分享时只留项目 GitHub 或本页链接，也请尽量避免大范围主动发帖宣传。

请勿分发原版或补丁后的 XAPK。 转发安装包或上传网盘，可能让维护者收到版权投诉，甚至导致项目下架。谢谢你帮我们照顾好这个小项目。
